Develop the Back-end part of the application using MongoDB
Aim:
To implement MongoDB database in our SkillSwap application using Node.js and Express.
Procedure / Requirements:
  • 1. MongoDB Atlas Account: Sign up for a free-tier account (500 MB storage) at https://www.mongodb.com/cloud/atlas.
  • 2. MongoDB Cluster: Create a free cluster (M0 Sandbox), choose AWS/Azure/GCP cloud provider, and select a region close to location.
  • 3. Database User & Network Access: Create a database user with username & password, and whitelist current IP (or 0.0.0.0/0 for global dev access).
  • 4. Connection String: Copy connection URI from Atlas → Connect → Drivers → Connection String. Example:
    mongodb+srv://username:password@cluster0.mongodb.net/skillswap?retryWrites=true&w=majority
  • 5. Programming Environment: Initialize Node project and install dependencies:
    npm install express mongoose cors dotenv
6. Backend Server Setup (server.js):
require('dotenv').config(); const express = require('express'); const mongoose = require('mongoose'); const cors = require('cors'); const app = express(); app.use(cors()); app.use(express.json()); const mongoURI = process.env.MONGODB_URI; mongoose.connect(mongoURI) .then(() => console.log('MongoDB connected successfully')) .catch(err => console.error('MongoDB connection failed:', err.message)); app.use('/api', require('./src/routes/api')); const PORT = process.env.PORT || 5000; app.listen(PORT, () => console.log(`SkillSwap Backend running on port ${PORT}`));
