Design the Backend part of Application using Django Framework
1. Aim
To design and implement a web-based Venue Booking Management System using the Django framework, following the Model-View-Template (MVT) architectural pattern, and to verify Django ORM operations, URL routing, form handling.
2. Algorithm / Procedure
  1. Install Python, pip, and Django (py -m pip install Django) inside a virtual environment.
  2. Create a Django project using django-admin startproject django_portal.
  3. Create a Django app using python manage.py startapp bookings.
  4. Register the app by adding 'bookings' to INSTALLED_APPS in settings.py.
  5. Define the Booking model in models.py with fields for venue, event, date, time slot, status, and purpose.
  6. Generate and apply migrations using makemigrations and migrate to create the database schema (Model layer).
  7. Write view functions in views.py: one to list/filter bookings and handle new-booking POST submissions, and one to expose a JSON API (View layer).
  8. Create a template (my_bookings_django.html) to render the booking list to the user (Template layer).
  9. Define URL patterns in the app's urls.py and include them in the project's urls.py using include().
  10. Write automated test cases in tests.py using Django's TestCase and Client to verify each view.
  11. Run python manage.py test to validate that all views behave as expected.
3. Program
